Design notes (4)
  • The console parses an etl-craft command line, calls the same /api/v1 action the CLI calls with --api, and prints the CLI's text output (or JSON with --json).
  • Never a shell: no host commands, no metadata edits. Mark, force, abort, rerun and offset resets prompt for a reason and a typed confirmation inside the console.
  • Tab completes commands and flags from the action table; ↑ recalls history from AUD_ACTIONS.
  • Every command is audited like any API call.
