Design notes (4)
  • Reads: PIPELINES /pipelines (with the S5.AB tag filter) and STATUS /status.
  • The tag tree is the S7.A.4 navigator: tags act as PowerCenter folders; a pipeline with two tags appears under both.
  • Recent-run squares link to each run; colour is backed by the status in each square's accessible name.
  • Gap: sort, name and status filters on PIPELINES are not request parameters yet.
